# Sweet Cloud Café

Sweet Cloud Café is a cute pastel-themed café website inspired by adorable characters, dreamy colors, and delightful treats. The website provides a simple and enjoyable way to explore the café's menu, discover product details, and learn more about the café.

## Features

- **Home Page** - Introduces Sweet Cloud Café and its concept.
- **About Page** - Shares the story and concept behind the café.
- **Menu Page** - Displays available drinks and desserts.
- **FAQ Page** - Answers frequently asked questions.
- **Contact Page** - Provides contact information.

## Getting Started

Clone this repository, then install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser to view the website.
